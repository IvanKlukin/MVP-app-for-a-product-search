# Руководство оператора магазина

Экран оператора предназначен для настройки плана магазина, привязки разделов и импорта товарного ассортимента.

## 1. Схема магазина

По умолчанию приложение использует встроенную нейтральную схему магазина.

### Выбор собственной схемы:
1. Нажмите кнопку **«Выбрать схему»**.
2. В системном окне выбора файлов выберите файл изображения (`.png`, `.jpg`).
3. Приложение скопирует выбранное изображение во внутреннюю память (`custom_store_map.png`). Схема останется доступна даже после перезапуска приложения или перезагрузки устройства.

### Сброс схемы:
Нажмите кнопку **«Сбросить схему»** для возврата к встроенному нейтральному плану магазина.

## 2. Размещение и управление разделами

### Добавление раздела:
1. Нажмите на нужную точку торгового зала на схеме.
2. В появившемся диалоговом окне введите уникальное название раздела (например, *«Бакалея»* или *«Молочные продукты»*).
3. Нажмите кнопку **«Сохранить»**.
4. На схеме появится синий маркер с подписью раздела.

### Просмотр и удаление разделов:
1. Нажмите кнопку **«Список разделов»**.
2. В появившемся списке выберите раздел, который требуется удалить.
3. Подтвердите удаление. Раздел и привязанные к нему товары будут удалены из базы данных магазина.

## 3. Импорт списка товаров

1. Нажмите кнопку **«Импорт товаров»**.
2. Ознакомьтесь с форматом:
   ```
   Название товара;Название раздела
   ```
3. Выберите файл `.txt` / `.csv` кнопкой **«Выбрать файл»** или нажмите **«Вставить пример»** для быстрой вставки образца.
4. Вы можете отредактировать строки в текстовом поле вручную.
5. Нажмите кнопку **«Импортировать товары»**.
6. Приложение выполнит валидацию:
   - Проверит наличие разделителя `;`.
   - Проверит наличие указанного раздела в магазине.
   - Если раздел отсутствует, строка помечается ошибкой и пропускается.
   - Если товар уже существует, его привязка к разделу обновляется (upsert).
7. Ознакомьтесь со сводкой: количество добавленных записей и список ошибок с номерами строк.

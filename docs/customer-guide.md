# Руководство покупателя

Режим покупателя предоставляет два ключевых сценария взаимодействия:
1. Поиск конкретного товара с наглядным указанием отдела на схеме магазина.
2. Пакетная проверка списка покупок из буфера обмена.

## 1. Поиск товара и схема зала

1. На главном экране выберите режим **«Покупатель»**.
2. В строке поиска начните вводить наименование товара (например, *«мол»* или *«ба»*).
3. При вводе от одной буквы автоматически формируется список подходящих товаров магазина (префиксный поиск).
4. Выберите нужный товар нажатием на строку в списке:
   - В информационной строке отобразится название товара и закрепленный за ним раздел.
   - На схеме магазина соответствующая метка раздела выделится увеличенным размером, контрастным красным цветом и внешним контуром.
5. Если товар отсутствует в каталоге, отобразится понятное сообщение: *«Товар не найден в каталоге магазина»*.

## 2. Поиск по списку покупок из буфера обмена

1. На экране поиска нажмите кнопку **«Список покупок»** (в правом верхнем углу).
2. Нажмите кнопку **«Вставить из буфера»**. Приложение извлечет текстовое содержимое из системного буфера обмена устройства.
3. Либо введите список товаров вручную в текстовое поле. Каждая позиция должна быть с новой строки. Допускаются стандартные маркеры списков:
   ```
   1. Молоко
   2. Батон
   - Сыр
   • Сок
   ```
4. Нажмите кнопку **«Найти товары»**.
5. Приложение обработает каждую позицию и сформирует список результатов:
   - Найденные товары помечаются зеленым статусом: `«Товар — Название раздела»`.
   - Отсутствующие товары помечаются красным статусом: `«Товар — Не найден»`.
   - Вверху отображается общая статистика: сколько позиций обработано, сколько найдено и сколько отсутствует.

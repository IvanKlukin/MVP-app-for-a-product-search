# MVP мобильного приложения поиска товара в магазине

## О проекте
Данный проект представляет собой автономное учебное мобильное приложение на платформе Android (вариант 6 рейтинговой работы), разработанное на языке **Java** с пользовательским интерфейсом на **XML Layouts**. 

Приложение решает задачу быстрой локализации товаров в торговом зале магазина без привлечения внешних серверов и сетевых подключений.

## Основные роли пользователей
1. **Оператор магазина**:
   - Настройка и просмотр схемы торгового зала.
   - Размещение меток отделов/разделов магазина нажатием на схему.
   - Пакетный импорт каталога товаров из файлов CSV/TXT или ручного ввода.
2. **Покупатель**:
   - Интерактивный поиск товаров по первым введенным буквам с подсказками.
   - Наглядная подсветка расположения отдела на схеме магазина.
   - Пакетная обработка списков покупок из буфера обмена смартфона.

## Ключевые архитектурные характеристики
- **Платформа**: Android SDK (Java 8 compatibility).
- **Минимальная версия**: `minSdkVersion 17` (Android 4.2 Jelly Bean).
- **Целевая версия сборки**: `compileSdkVersion 34`, `targetSdkVersion 34`.
- **Интерфейс**: Нативные XML-разметки на стандартной теме `Theme.Holo.Light.DarkActionBar`.
- **Хранение данных**: Локальная СУБД SQLite (`SQLiteOpenHelper`) с включенным каскадным удалением и контролем внешних ключей.
- **Относительные координаты**: Все метки отделов хранятся в нормализованных координатах `[0.0, 1.0]`, сохраняя позицию при смене ориентации экрана.

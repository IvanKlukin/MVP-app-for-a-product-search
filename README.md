# Поиск товаров в магазине (MVP)

## 1. Название проекта
**StoreSearchApp** — Мобильное приложение поиска товара в магазине (Рейтинговая работа, Вариант 6).

## 2. Назначение
Автономное локальное мобильное приложение на платформе Android для оперативной навигации покупателей по торговому залу и администрирования схемы отделов и товарного ассортимента оператором магазина.

## 3. Возможности оператора
- Просмотр схемы торгового зала магазина (встроенной нейтральной либо загружаемой пользовательской).
- Выбор пользовательского изображения схемы через `ACTION_GET_CONTENT` с автоматическим копированием во внутреннее защищенное хранилище приложения (`custom_store_map.img`).
- Интерактивное размещение меток отделов/разделов простым касанием схемы магазина.
- Автоматический пересчет и сохранение координат меток в относительных единицах `[0.0, 1.0]`, обеспечивающий независимость от разрешения и ориентации экрана.
- Просмотр списка созданных разделов и удаление разделов с каскадным удалением привязанных товаров.
- Пакетный импорт товаров из файлов `.txt` / `.csv` либо ручного ввода с валидацией разделителей и сопоставлением с существующими разделами.
- Защита от дубликатов: при повторном импорте существующего товара связь с разделом обновляется (upsert).

## 4. Возможности покупателя
- Быстрый префиксный поиск товаров по первым введенным буквам с выводом подсказок по мере ввода.
- Приоритет точного совпадения в поисковой выдаче.
- При выборе товара — наглядное отображение названия закрепленного отдела и статическое выделение его маркера на плане магазина (увеличенный радиус, контрастный красный цвет и внешнее кольцо).
- Информативное уведомление, если товар отсутствует в каталоге магазина.
- Пакетный поиск по списку покупок из системного буфера обмена (`ClipboardManager`) или многострочного ввода.
- Безопасная очистка маркеров списка (`1.`, `-`, `•`).
- Наглядный отчет сопоставления: статус «Товар — Название раздела» для найденных позиций и «Товар — Не найден» для отсутствующих позиций, а также сводка по количеству.

## 5. Ограничения MVP
- Полная автономность: отсутствие внешних серверов, REST API и облачных БД.
- Отсутствие аутентификации, паролей и ролевого разграничения доступа.
- Один торговый зал, один этаж, один магазин.
- Отсутствие GPS, геолокации, компаса и датчиков перемещения.
- Отсутствие расчета маршрутов и алгоритмов кратчайшего пути.
- Отсутствие корзины, кассовых операций и складского учета остатков.
- Отсутствие машинного обучения и нечеткого поиска.

## 6. Использованные технологии
- **Язык программирования**: Java (Java 8 compatibility).
- **Пользовательский интерфейс**: Нативные XML Layouts.
- **Тема оформления**: `android:Theme.Holo.Light.DarkActionBar` (базовая тема Android SDK, доступная с API 17).
- **База данных**: SQLite через `android.database.sqlite.SQLiteOpenHelper` с включенными внешними ключами (`setForeignKeyConstraintsEnabled(true)`).
- **Настройки и хранение файлов**: `SharedPreferences`, `openFileInput` / `openFileOutput`.
- **Графика**: Кастомный компонент `StoreMapView` с алгоритмом масштабирования `fitCenter` и безопасным декодированием растра через `BitmapFactory.Options.inSampleSize`.
- **Тестирование**: JUnit 4.13.2.
- **Документация**: MkDocs 1.6.1 (тема `readthedocs`).

## 7. Требования к окружению
- **JDK**: OpenJDK 21 (или JDK 17+).
- **Android SDK**: `platforms;android-34`, `build-tools;34.0.0` (или выше).
- **Gradle**: 8.14.3.
- **Android Gradle Plugin**: 8.11.1.
- **minSdkVersion**: 17 (Android 4.2 Jelly Bean).
- **compileSdkVersion / targetSdkVersion**: 34.

## 12. Формат импорта товаров
Текстовые строки в кодировке UTF-8 (с опциональным BOM) с разделителем `;`:
```csv
Название товара;Название раздела
```
Пример:
```csv
Молоко;Молочные продукты
Кефир;Молочные продукты
Батон;Хлеб
Вода;Напитки
```
Строки с неизвестными разделами пропускаются с указанием ошибки. Пустые строки игнорируются.

## 13. Демонстрационные данные
В приложении предусмотрена быстрая загрузка демо-данных кнопкой «Загрузить демо-данные»:
- **Разделы (5)**: Овощи и фрукты, Молочные продукты, Хлеб, Напитки, Бытовая химия.
- **Товары (10)**: Яблоки, Бананы, Молоко, Кефир, Батон, Хлеб ржаной, Вода, Сок, Мыло, Стиральный порошок.
- **Схема**: Встроенная нейтральная схема торгового зала (`default_store_map.png`).

## 15. Результаты тестирования
 
### 15.1. Автоматизированные модульные тесты (JUnit 4)
- **Всего модульных тестов**: 22.
- **Успешно пройдено**: 22 (100%).
- **Ошибок / провалов**: 0.
- **Покрытые компоненты**:
  - `SearchNormalizerTest`: 3 теста (нормализация регистра, удаление пробелов, замена «ё» -> «е»).
  - `ProductSearchServiceTest`: 4 теста (приоритет точного совпадения, поиск по мере ввода по префиксу, отсутствующий товар, пустой запрос).
  - `ProductImportParserTest`: 7 тестов (парсинг CSV, UTF-8 с BOM, пропуск пустых строк, фиксация синтаксических ошибок, отклонение строк с лишними полями, смешанные наборы, потоковое чтение исходного текста).
  - `ShoppingListParserTest`: 4 теста (Windows/Unix переводы строк, очистка маркеров списков, группировка статусов).
  - `StoreMapCoordinatesTest`: 4 теста (масштабирование fitCenter, round-trip преобразование координат, проверка границ).

### 15.2. Ручные функциональные проверки
Выполнены на эмуляторе Android 14 (API 34, образ `x86_64`, разрешение экрана 480×800 px, плотность 240 dpi):
1. Запуск приложения и проверка нулевого состояния БД.
2. Загрузка стандартного демонстрационного каталога (5 разделов, 10 товаров).
3. Просмотр схемы торгового зала и интерактивная расстановка меток по нажатию.
4. Выбор пользовательской схемы через `ACTION_GET_CONTENT` и сброс к нейтральному плану.
5. Просмотр списка разделов и удаление с каскадной очисткой привязанных товаров.
6. Пакетный импорт данных из файла и ручного ввода с предпросмотром исходного текста и строгой валидацией ровно 2 полей (`Товар;Отдел`).
7. Обновление связей товаров при повторном импорте (upsert).
8. Поиск товара по мере ввода с подсказками и статическим выделением метки отдела.
9. Поиск отсутствующего товара с выводом предупреждения.
10. Пакетная обработка списка покупок из системного буфера обмена.
11. Сохранение относительных координат меток при переключении Portrait/Landscape.
12. Сохранение всех данных в SQLite при перезапуске приложения.

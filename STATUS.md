# Текущий статус проекта (STATUS)

## 1. Общий статус проекта
**Готов к независимому аудиту**. Все обязательные функции оператора и покупателя полностью реализованы, модульные тесты выполнены на 100%, чистая сборка APK завершена успешно, документация и реальные скриншоты подготовлены.

## 2. Что реализовано
- Главный экран с выбором роли («Оператор», «Покупатель»), счетчиком базы данных, загрузкой демонстрационных данных и очисткой базы.
- Режим оператора с интерактивной схемой магазина, добавлением меток разделов по касанию, пересчетом в относительные координаты `[0.0, 1.0]`, списком разделов и удалением с каскадным удалением товаров.
- Выбор пользовательской схемы через `ACTION_GET_CONTENT` с сохранением во внутреннее хранилище приложения и кнопкой сброса к нейтральной стандартной схеме.
- Экран импорта товаров из файлов `.txt` / `.csv` и ручного ввода с валидацией разделителя `;`, проверкой наличия разделов и обновлением связей (upsert).
- Экран поиска товаров для покупателя с префиксным поиском, подсказками по первым буквам, приоритетом точного совпадения, выводом названия раздела и статическим выделением метки на схеме торгового зала.
- Экран пакетного поиска по списку покупок с получением данных из буфера обмена (`ClipboardManager`), очисткой маркеров и цветовой индикацией статусов («Найдено: Раздел» / «Не найден»).
- Поддержка портретной и альбомной ориентаций экрана без потери данных и смещения координат меток.
- 19 автоматизированных модульных тестов JUnit 4.
- Полная документация в Markdown и настроенный статический сайт MkDocs.
- 9 категорий реальных скриншотов с работающего Android эмулятора.

## 3. Что не реализовано (Non-Goals по границам MVP)
- Внешний сервер, облачная синхронизация, REST API.
- Авторизация, регистрация и роли с паролями.
- Поддержка нескольких магазинов и этажей.
- GPS, геолокация и трекинг покупателя.
- Построение пешеходных маршрутов между отделами.
- Складской учет остатков и корзина покупок.
- Сканирование штрихкодов камерой.
- Нечеткий поиск (Levenshtein) и нейросетевые модели.
